# **Orbit**

## **Social Media App (Android Version)**

**Orbit** is a feature-rich social media application built with **Flutter** and **Firebase**, designed to deliver a seamless, modern user experience. With a clean architecture and an intuitive interface, Orbit blends the interactive nature of Reddit and the visual appeal of Instagram into one cohesive platform.

---

## 📱 Key Features

### Authentication
- Firebase email/password login and registration with Email verification
- Secure account creation only upon verified emails
- Persistent sessions with full logout and redirect handling

### User Profiles
- Unique `@userTag` system with Firestore-based validation
- Profile setup: name, tag, gender, DOB, profession, location
- Instagram-style profile UI with editable sections
- Upload and manage profile & banner images (Cloudinary)

### Post & Thread System
- Full-page post creation with enhanced UI and icons
- Threads with upvote/downvote support and real-time interaction
- Compact, minimal action bar (upvote, comment, share)
- Full-screen media viewer with hero animations, swipe-down dismiss, and post preview

### Interaction & Engagement
- Reddit-style threaded comment section
- Save posts (thread saving like Reddit/Instagram)
- Follower/Following system with dedicated UI
- Share posts with dynamic counter and interactive layout

### Settings & Personalization
- Modern toggle-based settings (notifications, theme, accessibility)
- System theme sync and dynamic theme behavior
- Help Center and FAQ pages with consistent styling
- Application Info page with open-source reference
